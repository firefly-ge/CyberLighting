# CyberLighting

## Product prototype

Open [`prototype/index.html`](prototype/index.html) through a static HTTP server. The prototype is isolated from the current breathing-light homepage and demonstrates the proposed eight-page product flow:

- landing page and live scene preview;
- template exploration;
- quick scene creation;
- immersive player and sharing controls;
- local My Screens collection;
- image pixelization;
- advanced pixel studio;
- simulated multi-screen rooms.

From the repository root, a simple local preview is available with:

```powershell
npx serve .
```

Then open `/prototype/` from the printed local URL.
