# 整体像素爱心呼吸动画

## 目标

在固定网格中呈现一颗连续、完整的像素爱心。它像一盏整体呼吸灯一样从小到大、再从大到小，而不是由互不相关的格子闪烁构成。

## 视觉原则

- 爱心大小由一个全局、统一的呼吸曲线控制。
- 相邻格子的颜色深浅接近；局部变化只用于消除机械感。
- 爱心边缘随尺寸平滑扩展和回落，不出现洞、断层或随机跳格。
- 静止网格维持深色背景，爱心边缘允许一到两格的暗红过渡。

## 动画模型

1. 使用正弦曲线驱动 `breathingSize`，在小爱心和最大爱心之间连续变化。
2. 每一帧用相同的 `breathingSize` 重新判断所有格子是否属于当前心形；不对 Canvas 或单个格子使用独立的尺寸动画。
3. 用心形隐式函数计算 `heartFill`。边缘采用连续覆盖值，而非二元开关，因此颜色会自然过渡。
4. `localGlow` 只在约 ±6% 的范围内改变亮度，且使用低频、空间连续的相位，保证相邻格子看起来属于同一块灯墙。

## 当前参数

| 参数 | 当前值 | 作用 |
|---|---:|---|
| 网格 | 28 × 28 | 默认可读性与像素感的平衡 |
| 呼吸频率 | 1.25 rad/s | 约 5 秒完成一次循环 |
| 最小尺寸 | 0.52 | 保证最小状态仍能读作爱心 |
| 最大尺寸 | 1.00 | 对应完整爱心 |
| 局部亮度差 | ±6% | 保持整体一致但不死板 |

## 可复用方式

这个模型可迁移到其他像素图案：保留“全局尺寸/形状曲线 + 连续边缘覆盖 + 低幅局部亮度”的三层结构；只替换图案的距离函数或像素遮罩即可。
